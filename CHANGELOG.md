# Change Log

All notable changes to the "loci-syntax" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

## [0.2.1]
- Expand rule header highlighting for real-world Loci forms such as `blackbox`, `conditional(...)`, `inplace(...)`, `parametric(...)`, `comments(...)`, and standalone `prelude`/`compute`/`postlude` blocks
- Broaden `$type` declaration coverage for storage kinds seen in production code, including `Constraint`, `storeVec`, and `MapVec`
- Document the current Marketplace packaging and publish workflow

## [0.1.0]
- Expand grammar to highlight rule kinds, Loci directives, comments, literals, and constants
- Add activation events, keywords/category metadata, and documentation for install/usage

## [0.0.1]
- Initial release
